# AI-помощник для первичной обработки входящих заявок

Веб-приложение для автоматической первичной обработки и квалификации входящих заявок клиентов с использованием нейросети **GigaChat API**. Позволяет менеджеру за 5–20 секунд получить структурированную карточку разбора заявки с рекомендациями по дальнейшей работе.

## Ключевые возможности

- **Анализ заявок на основе GigaChat** — полноценный AI-анализ без заглушек, с реальным обращением к API
- **Автоматическая квалификация лидов** — определение типа лида (Целевой/Нецелевой/Неясно), выявление потребности клиента
- **Структурированная карточка разбора** — компания, суть запроса, известные/недостающие данные, следующий шаг, черновик ответа
- **Защита персональных данных** — автоматическая анонимизация ПДн перед отправкой в нейросеть с последующей обратной подстановкой
- **Интеграция с Битрикс24** — автоматическое создание лида и задачи при необходимости передачи заявки менеджеру
- **Тестовые примеры** — встроенные шаблоны заявок для быстрой проверки работы
- **Соблюдение бизнес-правил** — запрет на необоснованные обещания по ценам/срокам, корректная обработка жалоб и конфликтных ситуаций

## Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/ai-lead-assistant.git
cd ai-lead-assistant
```

### 2. Установка зависимостей

**Windows (автоматически):**
```bash
start.bat
```

**Ручная установка:**
```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
# source .venv/bin/activate  # Linux/Mac
pip install -r requirements.txt
```

### 3. Настройка GigaChat API

1. Получите ключ авторизации в [Сбер Developers Studio](https://developers.sber.ru/studio) (раздел «Настройки API» → «Получить ключ»)
2. Скопируйте `.env.example` в `.env`:
   ```bash
   copy .env.example .env  # Windows
   # cp .env.example .env  # Linux/Mac
   ```
3. Откройте `.env` и добавьте ключ:
   ```env
   GIGACHAT_AUTHORIZATION_KEY=ваш_ключ_авторизации
   GIGACHAT_SCOPE=GIGACHAT_API_PERS
   GIGACHAT_MODEL=GigaChat-2-Pro
   ```

### 4. Запуск приложения

```bash
python app.py
```

Откройте в браузере: [http://127.0.0.1:5000](http://127.0.0.1:5000)

## Как использовать

1. **Заполнение формы** — введите имя, телефон, email (опционально) и текст заявки. Или используйте одну из тестовых кнопок
2. **Анализ** — нажмите «Обработать». Процесс займет 5–20 секунд
3. **Изучение результата** — получите карточку разбора с типом лида, рекомендациями и черновиком ответа
4. **Дальнейшие действия** — скопируйте черновик ответа или при необходимости передайте заявку менеджеру (автоматически создастся лид в Битрикс24, если настроено)

## Конфигурация

| Переменная | Обязательная | Описание | По умолчанию |
|---|---|---|---|
| `GIGACHAT_AUTHORIZATION_KEY` | Да | Ключ авторизации из Сбер Developers Studio | — |
| `GIGACHAT_SCOPE` | Нет | Область доступа (`GIGACHAT_API_PERS` для физлиц, `GIGACHAT_API_B2B`/`GIGACHAT_API_CORP` для юрлиц) | `GIGACHAT_API_PERS` |
| `GIGACHAT_MODEL` | Нет | Модель GigaChat | `GigaChat-2-Pro` |
| `BITRIX_WEBHOOK_URL` | Нет | Webhook URL для интеграции с Битрикс24 | — |
| `GIGACHAT_CA_BUNDLE` | Нет | Путь к кастомному сертификату | — |

## Проверка работоспособности

```bash
python check_connection.py
```

Скрипт проверит наличие ключа, авторизацию и доступные модели.

## Особенности безопасности

- **Анонимизация** — персональные данные (ФИО, телефоны, email) автоматически маскируются перед отправкой в GigaChat
- **Ключи не попадают в браузер** — авторизация происходит на стороне сервера
- **Секреты в .gitignore** — `.env` исключен из системы контроля версий
- **Защита от HTML-инъекций** — вывод модели экранируется
- **Логирование анонимизации** — все операции анонимизации сохраняются в `logs/anonymization.csv`

## Сертификаты Минцифры

Для работы с GigaChat в России требуется сертификат НУЦ Минцифры. Приложение автоматически скачивает его при первом запуске в папку `certs/`. При проблемах с автозагрузкой см. [инструкцию в README](README.md#8-сертификаты-минцифры).
