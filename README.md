# AI-помощник для обработки входящих заявок (MVP)

Веб-приложение на одной странице: менеджер заполняет форму заявки (имя,
телефон, почта и текст заявки), нажимает «Обработать» и получает карточку с
разбором заявки — компания, суть запроса, тип лида, известные и недостающие
данные, следующий шаг, черновик ответа и признак того, что заявку нужно
передать человеку.

Анализ делает настоящий **GigaChat API** (документация: <https://developers.sber.ru/docs/ru/gigachat/api/overview>).
Заглушек и «настоящих» ответов без модели здесь нет: если ключ не задан или
GigaChat недоступен — приложение честно покажет ошибку.

Все данные в проекте синтетические.

---

## 1. Что нужно для запуска

| Что | Зачем | Уже есть? |
|---|---|---|
| Python 3.10 или новее | Язык, на котором написано приложение | Проверьте: `python --version` |
| Веб-браузер | Открыть страницу приложения | Есть в любой Windows |
| Ключ авторизации GigaChat | Доступ к модели | Нужно получить (шаг 2) |

Три дополнительные библиотеки ставятся автоматически при первом запуске
(`flask` — веб-сервер, `requests` — запросы в интернет, `python-dotenv` — чтение
файла `.env` с ключом).

---

## 2. Получить ключ авторизации GigaChat

1. Откройте <https://developers.sber.ru/studio> и войдите под своим Сбер ID.
2. Создайте (или откройте) проект **GigaChat API**.
3. В левой панели: **Настройки API** → кнопка **Получить ключ**.
4. Скопируйте поле **Authorization Key** (оно показывается один раз).

Ключ выглядит как длинная строка в кодировке Base64. **Никогда не присылайте его
в чат и не публикуйте** — он равносилен паролю от вашего API.

---

## 3. Вписать ключ в файл `.env`

Файл `.env` уже создан в папке проекта — откройте его и впишите ключ после
`GIGACHAT_AUTHORIZATION_KEY=`:

```
GIGACHAT_AUTHORIZATION_KEY=ваш_ключ_сюда
```

**Как открыть `.env` (файл без расширения, обычный Проводник его не показывает):**
1. Откройте папку проекта в Проводнике.
2. Включите показ скрытых файлов: Проводник → вкладка «Вид» → галочка
   «Скрытые элементы».
3. Кликните правой кнопкой по файлу `.env` → «Открыть с помощью» → «Блокнот».

**Если файла `.env` нет** (например, вы его случайно удалили) — создайте его
копией из шаблона `.env.example` одной командой в терминале (из папки проекта):

```powershell
Copy-Item .env.example .env
notepad .env
```

Файл `.env` уже добавлен в `.gitignore` — случайно отправить ключ в git не получится.

Что ещё можно поменять в `.env`:

| Параметр | Значение | Комментарий |
|---|---|---|
| `GIGACHAT_AUTHORIZATION_KEY` | ключ из личного кабинета | обязательный |
| `GIGACHAT_SCOPE` | `GIGACHAT_API_PERS` | для физических лиц. Для юрлиц: `GIGACHAT_API_B2B` (пакеты токенов) или `GIGACHAT_API_CORP` (оплата по факту) |
| `GIGACHAT_MODEL` | `GigaChat-2-Pro` | модель. Другие: `GigaChat-2-Max`, `GigaChat-2-Lite`, `GigaChat-3-Ultra` |
| `GIGACHAT_CA_BUNDLE` | пусто | путь к файлу сертификатов, если нужен свой |

## 4. Запуск

### Способ А — в один клик (Windows)

Дважды кликните по файлу **`start.bat`** в папке проекта. Он сам создаст
виртуальное окружение, поставит библиотеки и запустит приложение.

### Способ Б — команды в терминале (из папки проекта)

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python app.py
```

*Что такое виртуальное окружение:* это отдельная «песочница» для библиотек
проекта. Она нужна, чтобы ничего не ломать в системном Python. Её достаточно
создать один раз.

После запуска в консоли появится адрес. Откройте его в браузере:

```
http://127.0.0.1:5000
```

Остановить программу: нажмите `Ctrl+C` в консоли.

## 5. Проверка подключения (необязательно, но полезно)

```powershell
python check_connection.py
```

Скрипт покажет, найден ли ключ, работает ли он и какие модели доступны. Сам ключ
на экран не выводится. Если здесь всё хорошо — значит приложение тоже заработает.

## 6. Как пользоваться

1. Заполните форму: имя (обязательно), телефон (обязательно), почта (если есть)
   и текст заявки. Можно вместо этого нажать одну из трёх кнопок с тестовыми
   заявками — кнопка заполнит все поля формы, а обработка запускается
   кнопкой **«Обработать»**.
2. Нажмите **«Обработать»**. Пока идёт запрос, показывается индикатор
   «Обрабатываем заявку…» (обычно 5–20 секунд). Когда ответ готов, индикатор
   исчезает и рядом с ним появляется подсказка «Карточка заявки готова».
3. Справа появится карточка с русскими названиями полей:

| Поле в карточке | Что значит |
|---|---|
| Компания | название компании клиента (или «не указано») |
| Суть запроса | 1–2 предложения о том, что нужно клиенту |
| Тип лида | Целевой / Нецелевой / Неясно (цветная метка) |
| Известные данные | что удалось вытащить из текста |
| Чего не хватает | каких данных не хватает для работы |
| Следующий шаг | одно конкретное действие менеджера |
| Черновик ответа | текст ответа клиенту (можно скопировать кнопкой) |
| Нужен человек | Да / Нет |
| Причина передачи человеку | почему заявку взял бы человек |

Если что-то пошло не так, над карточкой появится красный блок с понятным
объяснением и подсказкой, что делать.

## 7. Правила, которые применяет модель

- **Не выдумывать.** Нет данных — пишется «не указано».
- **Квалификация.** Целевой — тема компании и понятное намерение купить (даже
  если данных мало: «нужно несколько штук», «сколько стоят кресла» — это
  целевой лид, а недостающие данные попадают в «Чего не хватает»). Нецелевой —
  запрос вообще не про офисную мебель и её услуги. Неясно — из текста непонятно,
  о чём речь.
- **Жалоба на уже принятый заказ** — это не заявка на новую покупку, но тема
  заявки наша, поэтому тип лида «Неясно», а «Нужен человек: Да» — обязательно.
- **Мало данных** → в «Чего не хватает» перечисляется недостающее, а в
  «Следующий шаг» и в черновике задаются 1–2 уточняющих вопроса.
- **Никаких обещаний.** Цены, сроки, скидки и условия, которых нет в заявке, в
  черновик не попадают. Дополнительно сервер удаляет из черновика фразы с
  неподтверждёнными условиями (например «поставим за 3 дня», если в заявке
  про 3 дня не было) и показывает об этом подпись в карточке.
- **Передача человеку.** Жалобы, конфликты, угрозы отказа, требования возврата
  и нестандартные запросы → «Нужен человек: Да» с причиной и нейтральный
  черновик без обещаний.

## 8. Сертификаты (Минцифры)

Сервер GigaChat, который выдаёт токен доступа, работает на сертификате
НУЦ Минцифры. В стандартном наборе сертификатов Python его нет, поэтому
приложение **само скачивает** корневой сертификат в папку `certs/` при первом
обращении к API. Обычно этого достаточно.

Если автозагрузка заблокирована, скачайте сертификат вручную (из папки проекта):

```powershell
mkdir certs -Force
curl.exe -L -o certs\russian_trusted_root_ca_pem.crt https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt
```

Альтернатива — установить сертификат на уровне ОС: Госуслуги → раздел
«Сертификаты» → файл для Windows → двойной клик → «Установить сертификат» →
«Добавить в хранилище «Доверенные корневые центры сертификации»».

## 9. Если что-то не работает

| Сообщение на экране | Причина | Что делать |
|---|---|---|
| «Не задан ключ GigaChat…» | нет файла `.env` или пустое значение | Сделайте шаг 3 из README |
| «GigaChat не принял ключ авторизации…» | ключ скопирован не полностью | Скопируйте `Authorization Key` заново, без пробелов и кавычек |
| «GigaChat отклонил запрос токена…» | неверный `GIGACHAT_SCOPE` | Для физического лица должно быть `GIGACHAT_API_PERS` |
| «Не удалось проверить сертификат сервера GigaChat…» | нет сертификата Минцифры | Раздел 8 |
| «Не удалось связаться с GigaChat…» | нет интернета / firewall | Проверьте интернет, попробуйте позже |
| «Закончились токены GigaChat…» | кончился лимит токенов | Посмотрите остаток в личном кабинете Studio |
| «GigaChat вернул ответ, который не удалось разобрать» | модель ответила не по формату | Повторите запрос или чуть измените текст заявки |
| Ошибка при установке библиотек | нет интернета | Проверьте интернет и повторите `pip install -r requirements.txt` |
| «Не удалось запустить приложение… порт 5000 занят» | порт уже использует другая программа | Закройте её (например, другое окно с этим же приложением) и запустите ещё раз |

Если программа падает с ошибкой в консоли — посмотрите последние строки окна
терминала: там будет причина.

## 10. Проверка готовности (чек-лист)

- [ ] `python check_connection.py` → «Ключ работает», в списке есть модель из `.env`.
- [ ] `python app.py` → в консоли адрес `http://127.0.0.1:5000`, страница открывается.
- [ ] **Полная заявка** («Альфа-Логистик»): тип лида «Целевой», заполнены компания,
      количество мест, бюджет, сроки; «Нужен человек: Нет»; черновик без обещаний цены.
- [ ] **Неполная заявка** (вопрос о цене кресел): тип лида «Целевой», в «Чего не хватает»
      есть количество и бюджет; в «Следующий шаг» — 1–2 уточняющих вопроса; в черновике нет цен.
- [ ] **Конфликтная заявка** (жалоба на доставку): «Нужен человек: Да», указана причина
      (жалоба / возврат предоплаты), черновик нейтральный, без обещаний по срокам и деньгам.
- [ ] Пустое поле → понятное сообщение об ошибке, приложение не падает.
- [ ] В `templates/index.html` нет строки с ключом; `git status` не показывает `.env`.

---

## 11. Безопасность

- Ключ лежит только в `.env` на вашем компьютере, читается сервером и **никогда не
  попадает в браузер** (в HTML и JavaScript его нет).
- В логах и сообщениях об ошибках ключ не выводится.
- `.env` добавлен в `.gitignore`, `.env.example` содержит пустые значения.
- Ответ модели выводится в страницу как обычный текст (без выполнения HTML-кода).

## 12. Структура проекта

```
app.py                 веб-сервер: страница и приём заявки
gigachat.py            авторизация в GigaChat и запрос к модели
prompt.py              системный промпт и JSON-схема ответа
normalizer.py          приведение ответа модели к единому виду + защита от обещаний
samples.py             три тестовые заявки для кнопок подстановки
console.py             настройка кодировки консоли, чтобы русский текст не ломался
check_connection.py    проверка ключа и списка моделей
requirements.txt       список библиотек
.env / .env.example    ключ и его шаблон
.gitignore             защита секретов
start.bat              запуск в один клик (Windows)
templates/index.html   вся страница: разметка, стили и скрипт
certs/                 сертификат Минцифры (скачивается автоматически)
```

---

## 13. Как поменять модель

Откройте `.env` и замените значение `GIGACHAT_MODEL`, например на
`GigaChat-2-Max`. После этого перезапустите приложение. Список доступных моделей
показывает `python check_connection.py`.

---

## 14. Чего в этой версии нет (осознанно)

CRM, база данных, авторизация пользователей, интеграция с мессенджерами,
автоматический сбор заявок из почты, отправка ответов клиенту (черновик
существует только на экране), история обработанных заявок.
